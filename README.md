# BOOKS — 個人蔵書デジタル・アーカイブ

個人蔵書の書誌情報と「デジタル分身」（電子版・RAW スキャン・オンライン読書リンク）を管理するリポジトリ。電子書籍本体はリポジトリに入れず、取得元リンクとローカル保存先のみを記録する。

## 現在の蔵書

- 収録件数：**74 件**（catalog.json）
- 保管優先度内訳：A × 51 / B × 7 / C × 12 / D × 4
- ローカル電子ファイル：epub/pdf 25 点 + 漫画 RAW（rar）25 点（約 3.3 GB、gitignore 対象）

## 構成

```
BOOKS/
├── catalog.json    # 蔵書索引（機械可読。isbn/title/author/publisher/…/priority/remark/ebook_url）
├── books/          # 一冊ごとの書誌ファイル *.md（書誌 + デジタル分身）
├── index.md        # Pages トップ（catalog.json から生成。保管列あり、携帯リスト対象は赤色表示）
├── 携帯リスト.md    # 出張・旅行時の携帯リスト（実体必須 15 冊 + 電子版で可 52 件）
├── zlibr.py        # Z-Library 電子版の検索・取得ヘルパー
└── .gitignore      # *.epub/*.pdf/*.rar 等の電子書籍本体を除外
```

## ワークフロー

1. ISBN → 書誌調査（出版社サイト等で判型・発売日・定価・頁数を確認）→ `books/<ISBN>.md` を作成 + `catalog.json` に登録（status 既定「未読」）
2. 電子版の調査：z-library（`zlibr.py`）/ RAW サイト（manga-zip.my 等）→ ローカル保存するか、取得元リンクを記録
3. 電子書籍本体は一切 gitignore し、公開リポジトリには URL とローカル保存先のみを記載
4. `index.md` を catalog.json と同期 → commit & push（Pages 自動更新）

## zlibr.py の使い方

認証情報はプロジェクト外の `~/.env`（`chmod 600`）に保存：

```bash
source ~/.env && zlib-2   # アカウントを有効化し ZLIB_EMAIL/PASSWORD/SITE を export
.venv/bin/python zlibr.py search <書名>
.venv/bin/python zlibr.py download <書名> --format epub
```

- z-library eAPI 直結（form ログイン → 検索 → 詳細 → download_location）。SHA-1 工作量証明の対策を自動処理
- 書名・著者検索のみ対応（ISBN では検索不可）。無料アカウントはログイン頻度制限・日次ダウンロード枠あり
- 依存は `aiohttp` のみ（`.venv/`）

## 保管優先度 A / B / C / D

デジタル分身の取得可否に基づく分類（2026-08-15 監査、詳細は「監査記録」参照）：

- **A（最高保管）**：取得可能なデジタル版なし / 日文原版が実体のみ —— 実体を失うと内容を補えない（50 件）
- **B（継続追跡）**：日文原版の**代用**電子版あり（初版代改訂新版・版元違いで正文一致・上下合本・抜粋集）—— 実体に版価値が残る（7 件）
- **C（置換可）**：書号と**同版**の電子版あり —— 実体を失っても補える（12 件）
- **D（デジタルのみ）**：**実体なし**・デジタル版のみ所持（4 件：わが闘争×2、九条の大罪 16・17）

各書の分類は `catalog.json` の `"priority"`、`books/<ISBN>.md` の「保管優先度」行、Pages の「保管」列で確認できる。

## 監査記録（2026-08-15）

- **方法**：全書を `zlibr.py` で z-library 検索（日/中書名・著者の交叉検索）、NDL デジタルコレクションで館蔵デジタル化を確認。電子版と実体の**版元・刊行年・体裁**を照合して分類
- **境界事例（厳格に分類）**：
  - NARUTO 1：z-library に実体ファイルあり・公開リンクなし → 実質取得不可 → A（2026-08-15 以降 RAWOTAKU.com で閲覧可に）
  - 評解：小倉百人一首：古書・未検索 → A で厳格に
  - 起风了：追査で日文 epub（版元違い）を確認 → B
  - 文法詳解・口語法精説：絶版、外部スキャン本（千千図書/mtoou.info）は未収録 → A
  - 新明解古典文法・文型式古典文法入門：NDL 館内限定公開のみ → A
  - 九条の大罪・東京貧困女子。 各 15 巻：z-library 未収録・公式有料版未購入 → 実質不可取得 → A（2026-08-15 以降 manga-zip.my RAW をローカル保存）
  - 恋・廃墟に乞う：電子版は中国語訳のみ（日文原版は実体のみ）→ A（携帯リストにも反映）
